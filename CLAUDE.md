# Regras do projeto

- Antes de implementar qualquer alteração visual (cores, temas, ícones, layout, componentes de UI), criar um mockup e aprovar com o usuário antes de escrever o código. Não vale para correção de bug que restaura o comportamento/visual já especificado (ex.: um asset quebrado sendo trocado pelo original) — só para decisões novas de design.
